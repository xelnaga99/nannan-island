楠楠島 檔案結構
index.html      頁面骨架與載入畫面
style.css       全部樣式
js/config.js    設定檔：試算表 ID、音樂檔路徑（最常改這個）
js/app.js       主程式（3D 場景、角色、遊戲）
audio/day.mp3   白天音樂
audio/night.mp3 夜間音樂

上傳 GitHub：把整個資料夾內容（含 js、audio 資料夾）一起上傳覆蓋。
換音樂：用同名 mp3 覆蓋 audio 裡的檔案即可。
注意：直接雙擊 index.html 開啟時，瀏覽器會擋讀取音樂和試算表；請在 GitHub Pages 或本機伺服器上測試。
